# AutoTap OCR

Aplikasi Android untuk membaca huruf menggunakan OCR dan melakukan tap otomatis berdasarkan pemetaan target.

## Fitur
- Kotak OCR kuning yang bisa dipindahkan dan diubah ukurannya.
- Kotak target hijau dengan pemetaan huruf.
- Membaca huruf pertama pada area OCR.
- Melewati area kosong dan mencoba membaca kembali.
- Kontrol Start dan Stop.

## Platform
Android 12+
